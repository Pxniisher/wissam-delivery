WISSAM DELIVERY — PROTOTYPE PWA

Contenu :
- index.html : interface interactive de démonstration
- manifest.webmanifest : nom et paramètres d'installation PWA
- sw.js : cache hors ligne simple
- icon.svg : icône de démonstration

IMPORTANT :
Cette version est un prototype. Les commandes sont conservées uniquement dans la mémoire de la page et ne sont pas partagées entre appareils. Il n'y a pas encore de vrais comptes, de serveur, de notifications, de GPS réel ni de paiement intégré.

Pour l'installation PWA sur téléphone, le site doit être publié sur un hébergement HTTPS. Ouvrir le fichier HTML localement ne suffit pas à installer une PWA sur tous les appareils.
